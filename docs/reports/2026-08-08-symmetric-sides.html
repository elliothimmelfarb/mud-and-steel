Two Trenches, One Game

Player two was a spectator. What it took to give him the same war · 8 August (2026)

The first live two-player match found the Big Push was only half a game. The host played Mud & Steel; the joiner watched it. He had no build bar, no orders, no stores, and no way to send a man anywhere — four hotkeys that despatched a garrison squad, and nothing else. This is why, and what symmetry actually cost.

The report

“It was almost like they were just a spectator”

Exactly right, and the code said so out loud. Every act of command in the game layer began with the same line: 

confirmPlace()  { if (this.mySide !== 'brit') return false }
sellSelected()  { if (this.mySide !== 'brit') return }
issueOrder(id)  { if (this.mySide !== 'brit') return }
buyUpgrade(id)  { if (this.mySide !== 'brit') return }

The HUD then hid what was left, and the sim refused what got through anyway:

if (this.bottomEl) this.bottomEl.style.display = g.mySide === 'german' ? 'none' : ''
issueAssault(ctx, side, ...) { if (side !== 'brit') return }

None of this was an oversight to be patched. It was the honest surface of a much deeper assumption, and patching the surface would only have hidden it.

The cause

The German side was never a player. It was the wave.

Mud & Steel began as a wave-defence game, and its type system still described one. There were two entirely different kinds of soldier in it:

Unit — implicitly British

  • A named, crewed position with a post
  • Veterancy, deeds, letters home, a grave
  • Placeable, sellable, embodiable in first person
  • Goes over the top, consolidates, is recalled

Enemy — implicitly German

  • A loose soldier in an AI squad
  • A bounty and a behaviour state
  • Spawned in bulk by a director
  • No post, no name to speak of, no player

Unit had no side field at all — it did not need one, because there had only ever been one commander. And with one commander came one of everything else: one purse (s.req), one set of stores (s.upgrades), one set of standing orders (s.orders), one ctx.mods, one creeping barrage.

So player two's German seat could only speak the director's vocabulary — spawnsquad and gbarrage — because that was the only language the German half of the sim understood. The Big Push spec had called for “symmetric rosters in v1”. That was never actually built.

The reframe

There is only one kind of soldier on this battlefield

The tempting fix was to build the German commander a parallel interface over the enemy pool: a German build bar that spawns squads, German orders that map onto director calls. It would have been faster. It would also have been two implementations of one idea, drifting apart from the first commit, and player two would still not have had named men, veterans, consolidation or a rifle he could pick up himself.

Unit-with-crew and Enemy-in-squad are two encodings of the same thing. In the Big Push, both sides should be the first one. Enemy stays exactly as it is for classic wave-defence, where a faceless tide is the whole fantasy.

So Unit got a side, its crew got tagged to it, and every faction question in the sim was rewritten to ask rather than assume. In the Big Push, s.enemies is now empty: both armies are crewed units, fighting each other through one code path.

The other beneficiary

The AI commander now plays the game you are playing

The German AI could not stay on the old vocabulary once the German seat left it — and that turned out to be the point rather than the cost. It buys from the same roster, posts men along its own fire step, wires its own approaches, buys its own doctrine, and sends its own sections over the top. Every command it issues goes through the same applyCmd a human's does, so anything it can do you can do, and anything refused to you is refused to it.

  • Either chair is playable. ?play=bigpush&side=german seats you in the north trench and the AI in the south. It is the same brain; it never knew which side it was on.
  • A disconnect no longer ends the match. Losing the British player used to be an instant walkover, because no AI could hold that seat. Now either side gets picked up.
  • The three personas survive intact — Methodical fortifies and bites, Stosstrupp hoards for a big push behind a creeping barrage, Opportunist hits the thinnest stretch.
Dressing

The same roster, in the other army's words

Symmetric rosters were a deliberate v1 decision and they stay that way: not one statistic differs between the sides. But a commander should not be buying Lewis guns for the Kaiser, so the German seat's cards carry his own labels and his own money.

Proof

Determinism first, because lockstep forgives nothing

Both peers run the full sim and compare 32-bit state hashes every 30 ticks. A side-aware unit, two purses, two upgrade sets, two order sets and two barrages are all new hashed state; any one of them read from the wrong side on one machine and not the other is an instant desync.

And in two real browser tabs

The joiner — German, player two, the seat that started this — placed a rifleman on his own fire step, issued Take Cover, and bought Deep Revetting. All three crossed the wire and applied on the host: his purse fell 450 → 320 Rm on both machines, his upgrade landed in germanUpgrades and nowhere else, his Take Cover ran his clock while the British one stayed at zero, and the man who marched up was called Ulrich Oswald.

Left open

Two things, honestly

  • Balance is now a live question, and the lab says so. Across those 30 matches the scripted British probe commander lost 28, drew 1, won 1 — on near-level strength (91–94 against 95–99), so it is losing ground, not men. That is very probably the probe rather than the sim: it is a caretaker written for the old surface, capping at ten riflemen, banking the requisition it never spends, buying no doctrine, emplacing no machine guns and attacking once every ninety seconds. The German seat has stopped being a spawn table and become an opponent, and the old stand-in cannot answer it. Still: the economy is symmetric by construction and has never been played at genuinely even odds by two people. That is the next thing to find out, and it needs humans, not probes.
  • Embodiment in multiplayer is still off, for both sides equally. The command spine carries first-person now, so it is a playtest of the six-tick delay away rather than an architectural gap — and when it opens, it opens for player two on the same day.
